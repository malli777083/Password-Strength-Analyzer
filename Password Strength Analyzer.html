    How it works

    Entropy
    Length multiplied by log2 of the character pool (lowercase, uppercase, digits, symbols). More bits means harder to guess.
    Uniqueness
    Compares against common passwords, leetspeak versions (p@ssw0rd), sequences (abcd, qwer), repeats and years.
    Reuse prevention
    Passwords are hashed with PBKDF2-SHA256 (200,000 rounds) and a random 16-byte salt, so plain text is never stored.
    Suggestions
    Generated with the browser's cryptographically secure random generator.
